# АТ-ГрузАвтоЛайт

Грузоперевозки до 5 тонн в Минске. Борт 6,20 × 2,25 м. Телефон +375 44 758-98-11.

**Живой сайт:** https://romjjjke.github.io/gruzavtolight/

## Что внутри

- Герой с реальным фото загрузки и тремя цифрами: 5 т, 6,20 м, 2,25 м.
- Пин-сцена «борт в масштабе»: схема сверху с размерными линиями, заполняется по скроллу,
  показания от 0,00 до 6,20 м, метки листа 2,5 м, доски 3 м и шестиметрового пиломатериала.
- Кейсы на двух реальных снимках загрузок (пиломатериал, деревянная конструкция).
- Блок «что проверить до звонка»: вес, габарит, крепление, погрузка.
- Форма: маршрут, груз, вес, срок — уходит в WhatsApp, с валидацией и состояниями.

## Стек

React + Vite + TypeScript, GSAP + ScrollTrigger (лениво, только для пина), Lenis.
Шрифты самохостингом: Bitter 700 + Inter Tight 400/600, 72 KB на 6 файлов, метрические фолбэки
(`size-adjust` 111,9% и 98,6%), фото 92 + 51 KB с srcset на 640 px.

## Замеры

Lighthouse mobile (GitHub Pages): performance 97–98, accessibility 100, best practices 100, SEO 100.
LCP 2,3 с, CLS 0, TBT 0–70 мс. Ширины 320–1680 без переполнения, ошибок в консоли нет.
